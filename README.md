# C++ GCD & LCM Calculator (Reference Implementation)

C++の**参照（リファレンス）渡し**を活用して、1つの関数から**最大公約数（GCD）**と**最小公倍数（LCM）**を同時に効率よく計算・取得するサンプルプログラムです。

---

## 📌 概要 (Overview)
C++の関数は通常 `return` で1つの値しか返せませんが、引数に参照（`&`）を使用することで、複数の計算結果を呼び出し元へ直接返すことができます。
また、最大公約数の計算には**ユークリッドの互除法**を採用し、高速かつ安全に処理を行います。

---

## ✨ 特徴 (Features)
- **参照（リファレンス）の活用**: ポインタを使わずに、簡潔な記述で複数（GCDとLCM）の結果を取得できます。
- **効率的なアルゴリズム**: ユークリッドの互除法により、 $O(\log(\min(a, b)))$ の高速な計算を実現しています。
- **オーバーフロー対策**: 最小公倍数（LCM）を計算する際、先にGCDで割る順序 (`(a / gcd) * b`) にすることで、大きな数値同士の掛け算によるオーバーフローを防ぎます。
- **バリデーション**: 0以下の入力値に対する安全な早期リターン処理を備えています。

---

## 🚀 使い方 (Usage)

### 1. コードの保存
上記のC++コードを `main.cpp` という名前で保存します。

### 2. コンパイルと実行
ターミナル（コンソール）を開き、以下のコマンドを実行します。

```bash
# コンパイル (g++ の例)
g++ -O3 main.cpp -o gcd_lcm

# 実行
./gcd_lcm
# calculateGcdAndLcm
```
実行結果の例
--- 計算結果 ---
数値 1: 24
数値 2: 36
最大公約数 (GCD): 12
最小公倍数 (LCM): 72
💻 コード構成 (Code Structure)
// 最大公約数と最小公倍数を同時に計算する関数
void calculateGcdAndLcm(long long a, long long b, long long &gcd_result, long long &lcm_result);
​a, b: 計算対象の数値
​gcd_result: 最大公約数（出力用参照）
​lcm_result: 最小公倍数（出力用参照）
